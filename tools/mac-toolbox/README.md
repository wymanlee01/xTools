# mac-toolbox

macOS 菜单栏工具箱（应用名 xTools）。第一版：截图、贴图；后续：粘贴板。

- 技术栈：Swift 6 + AppKit，SwiftPM 构建，最低 macOS 14
- 设计文档：[docs/mac-toolbox-design.md](../../docs/mac-toolbox-design.md)

## 构建与运行

```bash
./scripts/test.sh          # 单元测试
./scripts/bundle.sh        # 生成 dist/xTools.app
open dist/xTools.app
```

只装命令行工具（没有 Xcode）也能构建。
测试请用 `scripts/test.sh`：它显式指定了测试宏插件路径。直接跑 `swift test` 偶尔会报
`plugin for module 'TestingMacros' not found`。

**签名**：系统按代码签名识别应用，屏幕录制权限绑定在签名身份上。
- 临时签名的身份是程序哈希，每次重新编译都会变，系统当成新应用，要重新授权。
- 用固定证书签名时，身份是“包名 + 证书指纹”，重新编译不变，授权一次即可。

`bundle.sh` 会自动使用钥匙串里名为 `xTools Dev` 的代码签名证书；没有时退回临时签名。
也可以用 `SIGN_IDENTITY="证书名称"` 指定其他证书。创建 `xTools Dev` 自签名证书：

```bash
cat > cert.cnf <<'EOF'
[req]
distinguished_name = dn
prompt = no
x509_extensions = ext
[dn]
CN = xTools Dev
[ext]
basicConstraints = critical,CA:false
keyUsage = critical,digitalSignature
extendedKeyUsage = critical,codeSigning
EOF
/usr/bin/openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 3650 -config cert.cnf
/usr/bin/openssl pkcs12 -export -inkey key.pem -in cert.pem -name "xTools Dev" -out xtools.p12 -passout pass:临时密码
security import xtools.p12 -k ~/Library/Keychains/login.keychain-db -P 临时密码 -T /usr/bin/codesign
rm key.pem cert.pem xtools.p12 cert.cnf
```

`security find-identity -p codesigning` 里显示 `CSSMERR_TP_NOT_TRUSTED` 是正常的（自签名证书未被系统信任），不影响签名。

## 当前功能

| 功能 | 操作 |
|---|---|
| 区域截图 | F1 或菜单栏「区域截图」（没开“将 F1、F2 等键用作标准功能键”时按 fn+F1） |
| 框选 | 拖拽；单击选中光标下的窗口（没有窗口则选整屏）；拖动选区内部可移动 |
| 调整选区 | 拖动 8 个手柄改大小；方向键移动 1 点，⇧+方向键移动 10 点 |
| 放大镜 / 取色 | 框选前和拖拽时跟随光标显示；框选前按 C 复制 HEX，⇧C 复制 RGB（颜色按 sRGB 换算） |
| 标注工具栏 | 按 iShot 1:1 复刻尺寸和布局；选区定下后出现在选区下方；选了工具后选区锁定 |
| 标注工具 | 1 矩形、2 椭圆、3 直线、4 箭头、5 画笔、6 马赛克、7 文字、8 步骤标注、9 高亮（聚光灯）；⇧ 画正方形/圆、锁 45° |
| 样式栏 | 大小、不透明度滑块；5 个预设色 + 自定义色（吸管按钮打开取色面板）；专属选项：矩形实心/圆角、椭圆实心、高亮矩形/椭圆、马赛克/毛玻璃、画笔单一颜色/高斯模糊/马赛克、文字背景（无/底色/描边）+ 背景色 + 字体 |
| 编辑标注 | 点中已有元素可拖动移动，样式栏回显它的样式；Delete 删除；滚轮调不透明度（步骤标注是改序号） |
| 撤销 / 重做 | ⌘Z 或工具栏按钮 / ⇧⌘Z（和 iShot 一样，工具栏没有重做按钮） |
| 悬浮提示 | 鼠标停在按钮上，工具栏上方弹出提示框（工具名 + 快捷键），6 秒后自动隐藏；跟随系统深浅色 |
| 单键快捷键 | 有选区后：1~9 切换工具、空格保存、回车复制；可在提示框的下拉框里改成 0~9 / A~Z（保存、复制还可选空格 ㄩ、回车 ↩），与已有按键冲突时自动互换 |
| 贴图（截图） | 工具栏「贴图」按钮或 T 键，把选区（含标注）贴在原位置 |
| 未完成 | OCR、长截图按钮先占位置灰；曲线箭头选项置灰 |

### 贴图

| 功能 | 操作 |
|---|---|
| 贴剪贴板 | F3 或菜单栏「贴剪贴板到屏幕」；支持图片、图片文件、PDF、文字（文字渲染成白底图片） |
| 隐藏/显示全部 | ⇧F3 或菜单栏 |
| 移动 / 关闭 | 拖动贴图任意位置；双击关闭；左上角关闭按钮 |
| 光晕 | 选中的贴图四周是蓝色光晕，未选中是灰黑阴影；右键「取消阴影」/ H 键关闭 |
| 缩放 | 滚轮（以鼠标为中心，滚得越快步长越大：1/5/10/20/30%）、触控板捏合；0 / 1 / 2 键 = 50% / 100% / 200%；最小 60×30 点，最大 800% |
| 透明度 | ⌥ + 滚轮，或鼠标移入后顶部的滑块（贴图够大时显示），10%~100% |
| 右键菜单 | 拷贝 ⌘C、另存为 ⇧⌘S、从文件打开（用其他应用打开）、阴影 H、50/100/200%、上下左右位移一个像素（方向键）、旋转、翻转、关闭 ⌘W、全部关闭 ⇧⌘W、隐藏/显示全部 |
| 未完成 | 保存至贴图库、对贴图再标注（菜单项置灰） |
| 复制 | 回车 / 双击选区 / ⌘C |
| 保存 | ⌘S，默认存到桌面 |
| 取消 | Esc / 右键 |

### OCR

| 功能 | 操作 |
|---|---|
| 识别 | 截图工具栏 OCR 按钮或 O 键；全局快捷键 F4（框选后回车 / 双击 / 点「识别文字」） |
| 规则 | 同 iShot：先识别二维码，有就返回二维码内容；否则用系统 Vision 精确识别（简繁中、英、法、意、德、西、葡） |
| 结果窗口 | 拷贝、拷贝后退出；取消换行、强制英文符号、连续识别模式（追加结果）、固定区域模式（快捷键直接识别上次区域）、窗口置顶 |
| 未完成 | 翻译（按钮置灰） |

### 录屏

| 功能 | 操作 |
|---|---|
| 开始 / 停止 | F5：框选区域 → 点「开始录制」或回车 → 3 秒倒计时 → 录制；再按 F5 或菜单栏计时里「停止录制」 |
| 暂停 / 继续 | ⇧F5 或菜单栏计时里的菜单；暂停期间的时间不会进视频 |
| 录制中 | 区域四周红色边框（暂停时橙色虚线），菜单栏显示 ● 计时；xTools 自己的窗口不会被录进去 |
| 选项 | mp4 / mov、15~60 帧、显示光标、显示鼠标点击、系统声音、麦克风、倒计时；保存路径、保存方式（本地 / 剪切板 / 两者）、完成时动作（无 / 自动播放 / 打开路径） |
| 未完成 | 录屏中标注、GIF 输出 |

## 偏好设置

菜单栏「偏好设置…」（⌘,）打开；隐藏菜单栏图标后，再次打开 xTools.app 即可打开。布局按 iShot 复刻（900×700，左侧菜单）。

| 页面 | 设置项 |
|---|---|
| 截图 · 偏好设置 | 区域截图快捷键；截图时截取光标、光标辅助十字线、添加阴影（大小、颜色）、增加圆角（大小）、右键点击退出截图 |
| 截图 · 保存 & 动作 | 保存格式（png/jpg/tiff/heic/pdf）、保存路径（固定文件夹或保存时选择）、图片质量（高清/普通 1 倍）、声效、保存时同时复制、sRGB 颜色描述；双击选区的动作；连按两次修饰键保存并用指定 App 打开 |
| 标注 | 各工具、贴图、保存、复制的单键快捷键；工具栏弹窗响应时间 |
| 贴图 | 贴剪贴板、隐藏/显示全部的快捷键；显示窗口按钮、双击关闭、固定在单个桌面、默认圆角、默认透明度 |
| 录屏 | 开始/停止、暂停/恢复快捷键；保存路径、保存方式、完成时动作；格式、帧率、倒计时、光标、点击、系统声音、麦克风 |
| OCR | 全局快捷键；取消换行、始终保存到剪切板、不打开窗口直接保存到剪切板 |
| 通用 | 隐藏菜单栏图标、开机自启动（需要应用放在“应用程序”文件夹）、权限、初始化 |

> 和 iShot 默认一致：复制、保存的截图默认加 18 点阴影和 18 点圆角，可在「截图 · 偏好设置」关掉。

## 目录

```
Sources/
├── App/                # 入口：注册模块、菜单栏
├── ToolboxCore/        # 底座：模块协议、快捷键、设置、权限、剪贴板、服务注册、PinService
├── FeatureScreenshot/  # 截图模块
├── FeaturePin/         # 贴图模块（实现 PinService，截图模块通过协议调用）
├── FeatureOCR/         # OCR 模块（实现 OCRService，通过 CaptureService 框选）
└── FeatureRecord/      # 录屏模块（通过 CaptureService 框选，ScreenCaptureKit + AVAssetWriter）
```

新增功能模块：建 `Sources/FeatureXxx/`，实现 `ToolModule`，在 `Package.swift` 和 `AppDelegate.modules` 各加一行。
功能模块之间不能互相 import，协作通过 `ServiceRegistry` 里的协议。
