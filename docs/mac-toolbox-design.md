# mac-toolbox 设计方案

macOS 菜单栏工具箱（xTools）。第一版做截图和贴图，功能对标 iShot Pro；第二个工具计划做粘贴板。

## 1. 目标与范围

| 阶段 | 内容 | 状态 |
|---|---|---|
| M0 | 底座、打包、权限引导 | 已完成 |
| M1 | 截图核心：冻结屏幕、遮罩、框选、窗口识别、调整手柄、放大镜和取色、复制和保存 | 已完成 |
| M2 | 标注工具栏（按 iShot 1:1 复刻布局）：矩形、椭圆、直线、箭头、画笔、马赛克、文字、步骤标注、高亮、样式栏、撤销重做 | 已完成；曲线箭头、调整已画元素大小待做 |
| M3 | 贴图：截图贴到屏幕、剪贴板贴图、缩放、透明度、右键菜单 | 已完成；贴图库、对贴图再标注待做 |
| 第二版 | OCR 和录屏 | 已完成；翻译、长截图、带壳截图、延时截图、贴图库待做 |
| 粘贴板 | 历史记录、搜索、分类、收藏、预览、自动粘贴、贴到屏幕、隐私忽略 | 已完成（自己设计） |

## 2. 技术选型

- Swift + AppKit，SwiftPM 构建，最低 macOS 14（用 `SCScreenshotManager` 截屏）。
- 不用 Electron/Tauri：截图遮罩、逐像素选区、窗口识别、悬浮贴图都是原生最顺。
- 不依赖 Xcode：只要命令行工具，`scripts/bundle.sh` 负责打包和签名。

## 3. 架构：宿主应用 + 功能模块

```
App ──▶ FeatureXxx ──▶ ToolboxCore
```

- `ToolboxCore`：模块协议 `ToolModule`、`ToolContext`，以及快捷键、设置、权限、剪贴板、服务注册。
- `FeatureXxx`：每个功能一个模块，只依赖底座；**模块之间禁止互相 import**，由 `Package.swift` 在编译期保证。
- 模块协作：底座里定义协议（如以后的 `PinService`），提供方模块注册到 `ServiceRegistry`，使用方按协议取用。
- 通用界面组件（`ToolboxUI`）等到第二个模块需要时再抽。

### 为粘贴板预留

| 底座能力 | 现状 | 粘贴板为什么需要 |
|---|---|---|
| `PasteboardService` 写入来源标记 | 已实现 | 识别“来自截图”的内容，避免重复记录 |
| 剪贴板变化监听 | 待做 | 系统没有变化通知，只能统一轮询 `changeCount` |
| 跳过敏感内容 | 待做 | 密码管理器复制的内容带隐藏标记，不进历史 |
| `PermissionCenter` 辅助功能权限 | 已实现 | “自动粘贴到当前应用”需要 |
| `SettingsStore` 按模块加前缀 | 已实现 | 设置互不干扰 |
| 按模块的存储目录、模块开关 | 待做 | 历史记录持久化（倾向 SQLite） |

不做动态插件加载，所有模块直接编译进 App。

## 4. 快捷键

iShot 默认全部用 ⌥+字母（⌥A 区域截图、⌥S 剪贴板贴图、⌥H 隐藏贴图等）。xTools 默认 F1（不带修饰键），和 iShot 不冲突。
Mac 键盘上 F1 默认是调亮度，没开「将 F1、F2 等键用作标准功能键」时要按 fn+F1。

## 5. 粘贴板模块（自己设计）

粘贴板没有参考任何现有软件的实现，按公开的常见功能自己设计：

| 部分 | 设计 |
|---|---|
| 监听 | 底座 `PasteboardService.onChange` 每 0.5 秒比较 `changeCount`，各模块共用一个定时器 |
| 跳过 | nspasteboard.org 约定的 Concealed / Transient / AutoGenerated 类型、1Password 类型；忽略列表里的应用；本模块回写时的来源标记 `clipboard` |
| 存储 | `items.json`（Codable）+ `images/*.png` + `rtf/*.rtf`；按内容 SHA256 去重；按条数和天数清理，收藏不清理 |
| 面板 | `.nonactivatingPanel` 浮动面板，不抢前台应用的焦点；粘贴 = 写回剪贴板 + 收起 + CGEvent 模拟 ⌘V（需辅助功能权限） |
| 样式 | 参考 PasteNow 官网公开截图（pastenow.app 的 main-screen 图）：默认贴屏幕右侧全高，可拖动、缩放并记住位置；毛玻璃圆角（`maskImage` 裁圆角）；顶栏图钉 / 贴右侧 / 搜索 / 齿轮；胶囊分类；统一 80 点高的圆角卡片（图标、最多三行内容并上下居中、右上时间、右下 ⌘N），左右边距相同，始终用浮动滚动条；颜色值铺色、代码黑底、图片缩略图；底栏条数。界面和图标自己实现，没有用它的资源 |
| 模块协作 | 图片“贴到屏幕”走 `PinService`；截图等写入时带的来源标记显示为“来自截图” |
